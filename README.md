
# GAMENGINE

### An independent multi-language game engine.

**Version:** 0.1.0  
**Status:** Foundation Development

GAMENGINE is an independent game engine project
designed to support both browser-based and native
desktop development.

## Vision

- 2D and 3D game development
- Native desktop editor
- Browser-based editor
- Modular rendering architecture
- Extensible scripting system
- Multi-language integration
- Physics and audio systems
- Asset management
- Game exporting

## Technologies

- C
- C++
- C#
- Lisp
- Java
- Ruby
- Python
- Rust
- JavaScript
- TypeScript
- HTML
- CSS
- Shell

## Current Features

- 3D viewport
- Basic scene management
- Cube creation
- Object selection
- Object inspector
- Position editing
- Object deletion
- Native C++ foundation

## Platforms

- Web
- Windows
- Linux
- macOS (planned)

## Project Structure

`src/` contains the browser editor and engine prototype.

`native/` contains the native C++ foundation.
